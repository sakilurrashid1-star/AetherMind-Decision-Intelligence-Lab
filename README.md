# ✦ AetherMind — Decision Intelligence Lab

AetherMind is an interactive decision-intelligence application that makes uncertainty, trade-offs and assumptions visible.

Instead of claiming to predict the future, it exposes a transparent heuristic model and lets the human challenge it.

## 🚀 Live

After enabling GitHub Pages:

`https://sakilurrashid1-star.github.io/AetherMind-Decision-Intelligence-Lab/`

## ✨ Core experience

- **Living decision model** — ambition, risk, time pressure, resources and uncertainty reshape the result.
- **Explainability trace** — users can inspect the factors behind the score.
- **Parallel futures** — Safe, Base, Volatile and Black-swan stress scenarios.
- **Adaptive execution plan** — the timeline changes with constraints.
- **Human challenge console** — intentionally perturb assumptions and observe model behavior.
- **Objective modes** — impact, stability, speed and learning.
- **Responsive product UI** — designed as an interactive software experience rather than a static calculator.
- **Zero dependency** — HTML/CSS/JavaScript only.

## 🧠 Concepts demonstrated

Decision modeling · weighted scoring · scenario analysis · counterfactual reasoning · sensitivity analysis · explainable systems · human-in-the-loop design · responsive frontend engineering.

## 🛠️ Run locally

Open `index.html` in a modern browser or serve the repository with any static web server.

## 🌐 GitHub Pages

GitHub Pages can publish an `index.html` from the repository's publishing source. Configure **Settings → Pages → Deploy from a branch → main → /(root)**. GitHub notes that publication can take several minutes after changes are pushed.

## 🔐 AI roadmap

The architecture is intentionally frontend-first. Future versions can add a secure server-side AI gateway for natural-language decision briefs, multi-agent debate, voice interaction and generated reports. **Never expose an OpenAI API key in client-side JavaScript or GitHub Pages.**

## ⚠️ Scope

AetherMind uses transparent illustrative heuristics. Its scores are not predictions, financial advice, medical advice, or professional recommendations.
